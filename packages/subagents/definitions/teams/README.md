# Domain Teams

Each folder under `teams/` is a domain-specific team.

Current:
- web/ — Web Development team (planner, coder, reviewer)

Planned (added one-by-one by automation):
- mobile
- backend
- devops
- data-ml
- frontend-ui
- security
- testing
- desktop-ide
- agent-systems

Every team inherits the project SDD constitution and produces its own lightweight team-spec for features and acceptance criteria.
Shared cross-cutting agents: Install, Search Master, Memory Curator, Omni Router (later).
